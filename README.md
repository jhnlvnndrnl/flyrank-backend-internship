# FlyRank Backend Engineering Internship

This repository contains my backend engineering internship assignments and exercises completed throughout the internship.

Instead of creating a separate repository for each assignment, I chose to organize all weekly work in a single repository to keep the project history centralized and make progress easier to follow.

## Repository Structure

```
.
├── week_1/
│   └── BE-01/
├── week_2/
│   └── ...
├── week_3/
│   └── ...
└── README.md
```

Each week's directory contains its own source code, documentation, and any supporting files required for that assignment.

## Objectives

- Complete weekly backend engineering assignments
- Practice backend development concepts
- Build clean, maintainable, and well-documented projects
- Track progress throughout the internship

## Technologies

Projects in this repository may use:

- Python
- FastAPI
- REST APIs
- Next.js
- Git & GitHub

Additional technologies will be added as new assignments are introduced.
