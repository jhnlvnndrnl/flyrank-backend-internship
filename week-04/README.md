# Week 04: Backend Authentication & Identity Management

This directory contains the Week 4 internship deliverables focusing on secure backend authentication, identity management with Supabase Auth, JWT verification, and OpenAPI Swagger bearer security.

---

## Deliverables Summary

- **Backend Track (`BE-05`)**: [`backend/BE-05`](backend/BE-05/README.md) - **Auth · Login & Protect API**
  - Sign Up, Log In, Log Out, Token Refresh endpoints.
  - Supabase Auth SDK identity provider integration.
  - Reusable FastAPI `HTTPBearer` auth middleware dependency.
  - Public vs Protected endpoints (`/public/info`, `/protected/profile`, `/protected/dashboard`).
  - `401 Unauthorized` vs `403 Forbidden` status code handling.
  - OpenAPI Swagger UI `/docs` bearer authorization padlock integration.
  - Full `pytest` automated test suite and Stage 7 AI Rematch analysis.
